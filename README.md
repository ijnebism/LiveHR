# LiveHR
 
A lightweight desktop app built with C++ that connects to a generic Bluetooth heart rate strap and displays your live heart rate in real time.
 
## Table of Contents
- [Overview](#overview)
- [TechStack](#techstack)
- [Features](#features)

## Overview
LiveHR is a minimal desktop widget that connects to any generic BLE (Bluetooth Low Energy) heart rate strap and shows your live heart rate on screen. It uses the Windows Runtime Bluetooth APIs to scan for and connect to nearby devices, and an SFML-based window to render the display.

## Features
- **BLE Heart Rate Connection**: Scans for and connects to generic Bluetooth Low Energy heart rate straps using the WinRT Bluetooth APIs.
- **Live Heart Rate Display**: Shows your current heart rate in real time as data streams in from the strap.
- **Custom App Icon**: Distinct app and taskbar icon.
